# My Bindarr

这是我在 Bindarr 基础上维护的个人版本，包含本地中文 Pokémon 卡牌目录、卡图识别、卡组图片导入以及针对个人收藏流程的界面改进。

## 隐私与本地数据

仓库只保存程序代码和必要的前端构建文件。以下内容不会提交到 Git：

- API Key 与 `.env`
- 个人收藏数据库和备份
- HTTPS 私钥与证书
- `node_modules`
- 本地生成的识别模型、索引、所有卡图/上传图片和发布压缩包

运行前需要在 `app/app/backend` 中安装依赖，并从 `.env.example` 创建自己的 `.env`。本地数据库和识别数据需要单独保管或重新生成。

> 本仓库计划作为私人备份使用。上游项目及第三方卡牌素材的版权和许可仍归各自权利人所有。
