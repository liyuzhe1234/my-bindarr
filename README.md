# My Bindarr

这是我在 Bindarr 基础上维护的个人版本，包含本地中文 Pokémon 卡牌目录、卡图识别、卡组图片导入以及针对个人收藏流程的界面改进。

## 隐私与本地数据

仓库只保存程序代码和必要的前端构建文件。以下内容不会提交到 Git：

- API Key 与 `.env`
- 个人收藏数据库和备份
- HTTPS 私钥与证书
- `node_modules`
- 本地生成的识别模型、索引、所有卡图/上传图片和发布压缩包

运行前需要在 `app/app/backend` 中安装依赖，并从 `.env.example` 创建自己的 `.env`。本地数据库和识别数据需要单独保管或重新生成。

> 本仓库计划作为私人备份使用。上游项目及第三方卡牌素材的版权和许可仍归各自权利人所有。

## 启动

双击仓库根目录的 `启动 Bindarr.cmd`。启动器会优先运行当前源码，因此每次完成前端构建或后端修改后，重新启动即可看到最新版本。

- Bindarr 已在运行：直接打开网页，不会再启动第二份服务。
- 3001 端口被其他程序占用：显示占用程序并停止，避免出现难以理解的 `EADDRINUSE`。
- 启动失败：查看 `app/bindarr-server-error.log`。
- Node.js 不可用：自动回退到打包好的 `app/bindarr-server.exe`。

不要直接重复双击 `bindarr-server.exe`；日常使用统一从 `启动 Bindarr.cmd` 进入。
