Bindarr 高效录入工具

集中处理：单张图片识别、最近添加核对、卡组一键加入 Collection、中文分类修复。

返回 Bindarr

1. 单张卡图识别 → 加入 Collection

上传一张卡牌图片，先显示候选，确认后再加入 Collection。

2. 最近添加核对

显示最近加入 Collection 的卡，方便你检查是否加错、数量是否正确。

3. 一键“我拥有这个卡组”

选择一个 Deck，把里面所有卡按卡组数量加入 Collection。

4. 修复 Pokémon CN 分类

当 Collection 或 Deck Builder 里 Trainer / Pokémon / Energy 混在一起时，点这里重新修复本地中文库分类。

5. 卡组图片导入确认

卡组图片导入已经是“先识别、再确认、再创建”的流程。你可以继续使用这个入口。

打开卡组图片导入

6. 批量 Collection / Wishlist

在 Add Cards → Search & Add 搜索结果里点 Select，选择多张卡后，现在工具条会提供批量加入 Collection；我也会在原页面加上批量加入 Wishlist。
